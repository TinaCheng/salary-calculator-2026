# 2026 台灣月薪計算器

直接開啟 GitHub Pages 網址，或下載 index.html 後用瀏覽器開啟，即可使用。下載版不必安裝軟體或啟動伺服器。Safari、Chrome 或 Edge 皆可開啟 HTML；實際視覺版面尚未逐瀏覽器驗證。

## 如何填寫

1. 選擇薪資月份，填本薪、伙食、全勤、職務與其他津貼，以及 KPI、團體、專案獎金。金額以整元輸入。
2. 依公司設定，加班時薪固定為「本薪 ÷ 240」。津貼與獎金仍計入應發薪資。舊薪資檔與瀏覽器暫存載入後，也會依本薪重新計算加班費。
3. 填加班日期、日別、小時及分鐘。平日填正常 8 小時以外的加班；假日填當日出勤總時間。先扣除不計薪的休息時間，同一天合併一筆。跨日請按實際日期拆開；日別依排班與合法調移後的假日判定。
4. 投保預設以本薪對應 2026 級距。可改填勞保及健保申報薪資，並填健保眷屬。非整月投保、特殊身分或補助等請以保費帳單的實扣金額覆寫。
5. 其餘扣款依核薪結果填入。查看完整 20 欄薪資單後，儲存薪資檔或列印／另存 PDF。

批次貼上格式，每行一筆：

```text
2026-09-10,平日,2.5
2026-09-12,休息日,8
```

2.5 代表 2 小時 30 分；日別也可填「國定假日」或「特休」。日期須在選定月份內。例假緊急出勤請逐筆填寫並確認事由。

## 計算方式

- 應發總額 = 8 項本薪／津貼／獎金 + 免稅加班 + 課稅加班。
- 實領薪資 = 應發總額 − 10 項扣款。
- 平日加班：前 2 小時 × 1.34，後 2 小時 × 1.67。
- 休息日：前 2 小時 × 1.34，第 3～8 小時 × 1.67，第 9～12 小時 × 2.67。
- 國定假日／特休：有出勤、8 小時以內另加發一日工資；第 9～10 小時 × 1.34，第 11～12 小時 × 1.67。
- 例假因天災、事變或突發事件出勤：8 小時以內另加發一日工資；超過 8 小時 × 2。仍須另處理法定通報及事後補假。

加班三階段採用設定倍率 1.34、1.67、2.67（2026-09-16 更新），時薪保留完整精度，逐日總額最後無條件進位至整元。介面顯示的小數只是方便核對，計算不使用截短後的時薪。一般加班稅別按日期先後拆分 46 小時額度；假日及緊急例假依介面說明處理。稅別試算可由核薪者以「課稅加班金額調整」覆寫，不影響應發總額。

## 使用範圍

本工具處理 2026 年、全時月薪制、正常每日工時 8 小時及整月薪資。未自動處理部分工時、變形工時、到離職月比例計薪、補休折抵、平日或休息日的緊急延長工時、三個月工時累計、年度所得稅及健保補充保費。請假與出勤扣款、代扣稅金、福利金均由核薪者填入。

投保「以本薪估算」是依需求提供的試算模式。實際勞健保申報通常還須包含具工資性質的津貼、獎金等；不固定收入可能涉及平均薪資，請依實際核定金額確認。工具不把雇主應付的勞退 6% 或職災保費扣在員工身上。

一般勞保＋就保自付額採官方分擔表，健保採受僱者自付額表乘本人與最多 3 口眷屬。例：本薪 29,500、無其他項目及眷屬時，勞保含就保 738 元、健保 458 元，實領 28,304 元。

## 保存資料

瀏覽器會分月份暫存最後一次可成功計算的資料。新月份沿用薪資與投保設定，加班及扣款重新填寫。每月各一份，適合單人薪資試算；多人請各自儲存薪資 JSON 檔管理。

「儲存薪資檔」匯出目前月份的 JSON，之後可用「開啟薪資檔」還原。加班新增／編輯／移除、月份切換及開啟檔案可用「復原操作」還原，最多保留本次開啟期間的 30 次操作。

資料不會上傳。移動 HTML、改用不同瀏覽器或清除瀏覽器資料可能使暫存無法取得；請以匯出的薪資檔作長期保存。若瀏覽器限制本機檔案暫存，仍可計算、匯入、匯出及列印。

## GitHub Pages 發布

本專案為單一靜態 HTML，程式、樣式與 2026 年級距資料皆包含在 index.html，不依賴外部套件或後端。儲存庫只包含工具程式與說明，不包含任何使用者輸入的薪資檔。

1. 將本資料夾的檔案放在儲存庫 main 分支的根目錄。
2. 開啟 Settings → Pages。
3. 在 Build and deployment 選擇 Deploy from a branch，分支選 main，資料夾選 / (root)，然後 Save。
4. 發布成功後，使用 Pages 顯示的網址分享給同事。

一般 GitHub Pages 網站是公開可瀏覽的；私人儲存庫的 Pages 支援依帳戶方案而定。若僅使用私人儲存庫分享，請讓已受邀的同事下載 index.html，在本機開啟即可。
